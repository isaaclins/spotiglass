# Support Spotiglass

Spotiglass is a native macOS Spotify client built in the open (SwiftUI, OAuth PKCE, Web Playback SDK).

## Ways to help

- **Star the repo** — it helps others discover the project.
- **Report bugs or ideas** — [open an issue](https://github.com/isaaclins/spotiglass/issues) with steps to reproduce.
- **Contribute code** — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Tips (keeps releases shipping)

If Spotiglass saved you time or replaced a workflow you paid for elsewhere:

- [Buy Me a Coffee](https://buymeacoffee.com/isaaclins)

Rough guide: **$10** funds one focused evening of bugfixes, docs, or CI — I add a public thank-you in the changelog when tipped.

Other funding links appear via GitHub **Sponsor** on the repository home page (`.github/FUNDING.yml`).
