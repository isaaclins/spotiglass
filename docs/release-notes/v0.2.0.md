# Spotiglass v0.2.0

The equalizer release: Spotiglass now ships a working 10-band graphic EQ that actually colours the audio coming out of your speakers, plus a real in-app language switcher and a nicer Settings layout.

## Highlights

- **Working equalizer.** A custom CoreAudio HAL plugin (`SpotiglassEQDriver`) gets installed alongside the app. Audio is processed in-buffer with vDSP biquads and forwarded to the output device of your choice. Built-in presets and saved presets live in `~/.config/spotiglass/settings.json`.
- **Picks up your system volume.** The virtual EQ device mirrors the volume of whatever it's forwarding to, so the volume keys and menu-bar slider just work.
- **Translations that actually swap at runtime.** The in-app language picker (English, Español, Deutsch) now covers Settings, browsing, the command palette, lyrics, playlist menus, and the EQ UI — without needing a restart or a system-language change.
- **Playlist track-ops.** Shift-click to select a range of tracks, then run batch actions from the new track menu.
- **Click-to-seek lyrics.** Tap any synced line to jump playback there.
- **Settings, redesigned.** Two-pane Raycast-style layout that scales as more panels land.

## First-run notes for the equalizer

The HAL driver is code-signed with an Apple Development certificate. Most installs Just Work, but if you see **"EQ won't enable" / "device disappears"**, run:

```sh
bash scripts/setup-eq-driver-signing.sh
```

That imports and trusts the Apple Root CA in your login keychain, which is what `coreaudiod` checks when loading the bundle. See [docs/equalizer.md](https://github.com/isaaclins/spotiglass/blob/main/docs/equalizer.md) for the full architecture.

## Install

1. Download `Spotiglass-0.2.0.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into **Applications**.
3. First launch is Gatekeeper-blocked (build is unsigned beyond ad-hoc). Control-click → **Open** → **Open**, or:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Spotiglass.app
   ```

Existing 0.1.x users will be offered the update automatically via Sparkle.

Spotify **Premium** is required for Web Playback SDK streaming.
