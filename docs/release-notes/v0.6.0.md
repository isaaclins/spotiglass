# Spotiglass v0.6.0

Spotiglass can finally search Spotify itself, not just the library you already have.

## Highlights

- **A dedicated Search surface.** A new **Search** row sits at the top of the sidebar and opens a full-window view for searching Spotify's catalog: tracks, albums, artists, and playlists. Filter by category, page through results, and open any result the same way you would from your library.
- **Cmd+F opens Search, and you can change it.** The shortcut is registered as a normal editable command, so it appears in **Settings → Keyboard**, can be rebound, and takes part in conflict detection. Nothing is hardcoded.
- **The command palette hands off instead of competing.** Cmd+K behaves exactly as before, and palette results now end with **Show all results for your query**, which opens the Search view carrying your text and category.
- **Readable controls in background windows.** A selected filter pill drew as a white capsule with a white label when its window was not focused, which made the active category invisible. Labels on accent-filled controls now pick their color from the fill, so they stay readable whether the window is focused or not.

## Reliability

- The formatter configuration was invalid, so `make format` and `make lint` had never run for anyone. Both work now, and the violations they surfaced are fixed.
- A test file had never been added to the test target, so four component tests had never compiled or run once. They are part of the suite now.

## Install

1. Download `Spotiglass-0.6.0.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into **Applications**.
3. Launch Spotiglass normally. No Control-click or quarantine-removal workaround is required.

Existing users will be offered the update automatically through Sparkle.

Spotify **Premium** is required for Web Playback SDK streaming.
