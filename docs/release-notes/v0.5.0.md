# Spotiglass v0.5.0

A native-Mac release focused on making Spotiglass look, behave, and distribute like a first-party macOS app.

## Highlights

- **Settings now uses native grouped forms.** Equalizer, Playback, Appearance, Keyboard, and Account use consistent macOS sections, label columns, insets, and scrolling.
- **A real Mac menu bar.** The new **Playback** menu exposes play/pause, next, previous, shuffle, repeat, and connection actions. View and File menus include queue, lyrics, refresh, and library-loading commands, with shortcuts linked to your editable keymap.
- **Native playlist track tables.** Playlist tracks now use the macOS table implementation, bringing native selection, Shift and Command multi-select, arrow-key navigation, double-click playback, and correct context-menu focus rings. A 1,000-track playlist still realizes only the visible rows.
- **Better accessibility and discoverability.** Icon-only controls now provide concise hover tooltips and VoiceOver labels across playback, queue, browser, breadcrumbs, pinning, lyrics, and shortcut settings.
- **Correct background-window appearance.** Custom accent controls become neutral when a window is inactive, while warnings and artwork remain visible. Selection also de-emphasizes when keyboard focus moves elsewhere.
- **Quieter copy.** Command palette and queue section headers use locale-appropriate capitalization instead of all caps.
- **Trusted distribution.** The app, Sparkle components, equalizer driver, and disk image are signed with Developer ID, hardened, notarized by Apple, and stapled for offline Gatekeeper verification.

## Reliability

- Unit tests can no longer overwrite the real Spotify client ID, playback volume, or app-storage preferences.
- Release tooling validates version progression, keeps historical Sparkle download URLs pinned to their original tags, and refuses to publish an unsigned or unnotarized artifact.

## Install

1. Download `Spotiglass-0.5.0.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into **Applications**.
3. Launch Spotiglass normally. No Control-click or quarantine-removal workaround is required.

Existing users will be offered the update automatically through Sparkle.

Spotify **Premium** is required for Web Playback SDK streaming.
