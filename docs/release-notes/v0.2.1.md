# Spotiglass v0.2.1

A focused search release: the command palette now feels instant. Typing searches your already-loaded songs immediately and fills in Spotify catalog results as they arrive — no more staring at a spinner.

## Highlights

- **Local-first search.** Press ⌘K and start typing: matches from data already in memory (the open playlist's tracks and your library playlists) appear instantly on every keystroke. Spotify catalog hits merge in when they land, so the list never blanks or spins while you wait.
- **Instant filtering.** The footer pills (and Tab) now re-filter the results you already have instead of running a fresh network search, so flipping between **All / Tracks / Artists / This playlist / My Playlists** is immediate.
- **Smarter default.** **All** leads the footer as the default, and its sections are ordered by how closely each one matches what you typed — type an artist name and Artists floats to the top; type a song title and Tracks lead.

## Install

1. Download `Spotiglass-0.2.1.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into **Applications**.
3. First launch is Gatekeeper-blocked (build is unsigned beyond ad-hoc). Control-click → **Open** → **Open**, or:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Spotiglass.app
   ```

Existing 0.1.x / 0.2.0 users will be offered the update automatically via Sparkle.

The bundled equalizer driver is code-signed with an Apple Development certificate. If the EQ won't enable after updating, run `bash scripts/setup-eq-driver-signing.sh` (see [docs/equalizer.md](https://github.com/isaaclins/spotiglass/blob/main/docs/equalizer.md)).

Spotify **Premium** is required for Web Playback SDK streaming.
