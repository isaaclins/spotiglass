# Spotiglass v0.1.1

First downloadable build of Spotiglass for macOS — installable from the Releases page.

## Highlights

- **`.dmg` installer**: drag Spotiglass into Applications. (A Sparkle `.zip` is also attached for in-app auto-update.)
- Playlist browsing: hide the owner row when the playlist owner matches the signed-in user (#15).
- GitHub Funding / Buy Me a Coffee links surfaced on the repo and in `SUPPORT.md`.

## Install

1. Download `Spotiglass-0.1.1.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into the **Applications** folder.
3. First launch: the build is unsigned, so Gatekeeper will block it. Control-click the app → **Open** → **Open**, or run:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Spotiglass.app
   ```

Spotify **Premium** is required for Web Playback SDK streaming. See [Getting started](https://github.com/isaaclins/spotiglass/blob/main/docs/getting-started.md) for the Spotify Developer app setup.
