# Spotiglass v0.4.0

A feature release that makes playlist management easier and smooths out Settings, playback, and accessibility details.

## Highlights

- **Rename playlists in place.** Playlist owners can double-click the title in a playlist's detail header or right-click it and choose **Edit playlist name**. The new name appears immediately and returns to the previous name if Spotify rejects the change.
- **A more consistent Settings window.** Settings panes now share one scroll container, use consistent top padding and window width, and keep the traffic lights aligned with the main window. Raw settings JSON has one discoverable entry point, and the sidebar can be hidden and shown again.
- **Equalizer state is remembered.** The master enable and bypass setting is restored when the app launches.
- **Clearer menus and accessibility.** The duplicate Spotiglass menu is gone, and VoiceOver announces when a track is pinned.
- **More resilient browsing.** Followed playlists show a clear locked state when Spotify does not allow access to their tracks.

## Install

1. Download `Spotiglass-0.4.0.dmg` below.
2. Open the disk image and drag **Spotiglass.app** into **Applications**.
3. First launch is Gatekeeper-blocked because the build is unsigned beyond ad-hoc. Control-click, choose **Open**, then choose **Open** again, or:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Spotiglass.app
   ```

Existing users will be offered the update automatically via Sparkle.

The bundled equalizer driver is code-signed with an Apple Development certificate. If the EQ will not enable after updating, run `bash scripts/setup-eq-driver-signing.sh` (see [docs/equalizer.md](https://github.com/isaaclins/spotiglass/blob/main/docs/equalizer.md)).

Spotify **Premium** is required for Web Playback SDK streaming.
